# OpenBGI: the manual

OpenBGI plays visual novels made with the BGI/Ethornell engine. You
bring the game; OpenBGI replaces the game's own program.

## Quick start

1. Install OpenBGI: [install.md](install.md).
2. Start it. The launcher opens.
3. Click **Folders**, then **Add folder**, and choose the folder your
   games are in.
4. Select a game and click **Start game**.
